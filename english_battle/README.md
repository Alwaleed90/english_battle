# English Battle | مسابقة اللغة الإنجليزية المدرسية

**English Battle** هو موقع تعليمي تفاعلي مصمم خصيصاً لإدارة مسابقات وتحديات اللغة الإنجليزية التنافسية لطلاب المدارس في المملكة العربية السعودية (المرحلة الابتدائية، المتوسطة، والثانوية).

يعتمد الموقع على أسلوب **"الشاشة الواحدة داخل الفصل"** (Single-Screen Classroom Game)، حيث يتولى المعلم أو مدير المسابقة إدارة اللعبة من شاشة العرض أو السبورة الذكية دون حاجة الطلاب لأجهزة أو حسابات خاصة.

---

## 🌟 المميزات الرئيسية

1. **تقنيات أصيلة وخفيفة (Zero Dependencies):**
   - مبني بالكامل باستخدام **HTML5** و **CSS3** و **Vanilla JavaScript**.
   - لا يعتمد على React أو Vue أو أي إطار عمل أو Backend.
   - يعمل 100% دون اتصال بالإنترنت بعد تحميل الملفات.
2. **8 أنماط للتحديات اللغوية (متوافقة مع المناهج السعودية We Can / Super Goal / Mega Goal):**
   - **Word Meaning:** اختيار معنى الكلمة الإنجليزية باللغة العربية.
   - **Sentence Meaning:** فهم الجمل والتعابير الإنجليزية الشائعة.
   - **Grammar Challenge:** تحدي القواعد النحوية والأزمنة وحروف الجر والمبني للمجهول.
   - **Fill in the Blank:** إكمال الفراغ بالسياق اللغوي الصحيح.
   - **Word Scramble:** ترتيب الحروف المبعثرة لتكوين الكلمة المطلوبة مع تلميح تعريفي.
   - **Sentence Builder:** ترتيب الكلمات المبعثرة لبناء جملة إنجليزية ذات تركيب سليم.
   - **True or False:** تحديد صحة أو خطأ العبارة بأزرار كبيرة واضحة للشاشة.
   - **Guess the Word:** تخمين الكلمة عبر 3 تلميحات ذكية متدرجة.
   *(ملاحظة: خالٍ تماماً من التحديات الصوتية أو الاستماع وفقاً لشروط المشروع).*
3. **أدوات تحكم احترافية للمعلم:**
   - تحديد الفريق المجيب بنقرة واحدة أو باختصارات لوحة المفاتيح `[1-4]`.
   - كشف الإجابة الصحيحة `[A]` مع ظهور شرح تعليمي فوري باللغة العربية.
   - احتساب النقاط `[C]` مع قفل احتساب النقاط مرتين لمنع التكرار.
   - احتساب الإجابة الخاطئة `[W]` وتمرير السؤال لفريق آخر.
   - مؤقت تنازلي تفاعلي مع إمكانية الإيقاف المؤقت والاستئناف `[Space]`.
   - مكافأة سرعة اختيارية (+20% عند الإجابة خلال أول 30% من الوقت).
4. **منصة التتويج والإحصاءات:**
   - احتفالية فوز مع مؤثر بصري للكونفيتي (Confetti Canvas).
   - منصة الفائزين (Podium) للمراكز الأولى، مع معالجة ذكية لحالات التعادل.
   - جدول إحصائي مفصل لعدد الإجابات الصحيحة والخاطئة ونسبة دقة كل فريق.
   - تمييز الفرق في مجالات التحدي (Best in Category).
5. **مؤثرات صوتية اصطناعية (Web Audio API):**
   - توليد الأصوات برمجياً بدون ملفات صوتية خارجية لضمان عملها أوفلاين في أي بيئة مدرسية، مع زر لكتم الصوت.
6. **مرونة التشغيل والاعتمادية:**
   - متوافق مع شاشات العرض الكبيرة (Projectors 1080p/4K) والشاشات اللمسية والكمبيوتر والجوال.
   - يدعم التخزين المحلي `localStorage` لحفظ الإعدادات وسجل المسابقات واستعادة الجولة الحالية عند التحديث العرضي.

## 🚀 طرق تشغيل المشروع محلياً

لتشغيل المشروع وضمان تحميل ملفات `JSON` بسهولة، يمكنك استخدام إحدى الطرق التالية:

### الطريقة الأولى: التشغيل المباشر (Direct Double-Click)
بفضل وجود ملف `js/questions_data.js` المدمج مع نظام الفحص التلقائي، يمكنك ببساطة **النقر المزدوج على ملف `index.html`** لفتحه في أي متصفح حديث (Chrome, Edge, Safari, Firefox). سيعمل الموقع بكامل وظائفه ومؤثراته حتى تحت بروتوكول `file:///` المحلي دون مواجهة قيود CORS.

### الطريقة الثانية: عبر خادم محلي باستخدام Python (موصى بها)
إذا كان لديك Python مثبتاً على جهازك، افتح موجه الأوامر (Terminal / CMD) داخل مجلد المشروع ونفذ:
```bash
# Python 3
python -m http.server 8000
```
ثم افتح المتصفح على:
`http://localhost:8000`

### الطريقة الثالثة: عبر إضافة Live Server أو Node.js
- في **VS Code**: انقر بالزر الأيمن على `index.html` واختر **Open with Live Server**.
- أو باستخدام Node.js:
```bash
npx serve .
```

## 🌐 خطوات النشر على GitHub Pages

المشروع مصمم ليكون موقعاً ثابتاً (Static Site) جاهزاً للنشر المباشر والمجاني على GitHub Pages:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub باسم: `english-battle`.
2. ارفع ملفات المشروع إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "Initial release of English Battle"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/english-battle.git
   git push -u origin main
   ```
3. في صفحة المستودع على GitHub:
   - انتقل إلى **Settings** (الإعدادات).
   - اختر من القائمة الجانبية **Pages**.
   - تحت قسم **Build and deployment**، اختر المصدر: **Deploy from a branch**.
   - اختر الفرع `main` والمجلد `/ (root)`.
   - اضغط **Save**.
4. خلال دقيقة واحدة، سيمنحك GitHub رابطاً مباشراً لموقعك مثل:
   `https://YOUR_USERNAME.github.io/english-battle/`

## 📝 توسيع بنك الأسئلة (300 سؤال أو أكثر)

تمت هيكلة بنك الأسئلة في ملف `data/questions.json` بشكل قياسي يسمح بإضافة مئات الأسئلة الجديدة بكل سهولة.

### بنية كائن السؤال في JSON:
```json
{
  "id": "gr_050",
  "type": "grammar",
  "stage": "intermediate",
  "difficulty": "medium",
  "points": 150,
  "question": "Choose the correct preposition: She arrived _____ the airport on time.",
  "options": ["at", "on", "in", "by"],
  "correct_answer": "at",
  "explanation": "نستخدم حرف الجر 'at' للإشارة إلى نقاط الوصول والمباني المحددة مثل المطارات والمحطات.",
  "hint": "تستخدم مع المواقع المحددة بدقة."
}
```

### الحقول المدعومة:
- `id`: معرّف فريد لا يتكرر (مثل `wm_015`, `gr_020`).
- `type`: نوع التحدي من بين:
  `word_meaning` | `sentence_meaning` | `grammar` | `fill_blank` | `word_scramble` | `sentence_builder` | `true_false` | `guess_word`
- `stage`: المرحلة (`primary` | `intermediate` | `secondary`).
- `difficulty`: الصعوبة (`easy` | `medium` | `hard`).
- `points`: النقاط (افتراضياً: 100 سهل، 150 متوسط، 200 صعب).
- `question`: نص السؤال الواضح باللغة الإنجليزية.
- `options`: مصفوفة الخيارات (للأسئلة متعددة الخيارات).
- `correct_answer`: الإجابة الصحيحة المطابقة.
- `explanation`: شرح تعليمي مفيد باللغة العربية لترسيخ المفهوم للطلاب.
- `hints`: مصفوفة 3 تلميحات (خاصة بتحدي `guess_word`).

## ⌨️ اختصارات لوحة المفاتيح للمعلم

| المفتاح | الوظيفة |
| :--- | :--- |
| `1`, `2`, `3`, `4` | اختيار الفريق المجيب حالياً أو تحديد الخيار |
| `Space` (المسافة) | إيقاف المؤقت مؤقتاً أو استئنافه |
| `A` | إظهار الإجابة الصحيحة وكشف الشرح التعليمي |
| `C` | احتساب النقاط لصالح الفريق المحدد (مع مكافأة السرعة) |
| `W` | تسجيل إجابة خاطئة (بدون نقاط) |
| `Enter` | الانتقال للسؤال التالي أو التوجه لمنصة النتائج |
